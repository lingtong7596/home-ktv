# 家庭 KTV 🎤

一套跑在自己家里的卡拉 OK 系统：**飞牛 NAS 做曲库服务器，投影仪唱歌，手机扫码点歌**。
不依赖任何外网账号，全家局域网直接使用；NAS 端不转码，J1900 这类弱 CPU 也能跑。

```
┌──────────────┐   HTTP/SSE 实时同步   ┌──────────────────┐
│  飞牛 NAS     │◄────────────────────►│  投影仪            │
│  · 曲库扫描    │   全屏播放 KTV 视频    │  KTV Player APK   │
│  · 点歌 API   │   原唱/伴唱瞬时切换     │  （浏览器 /play 备用）│
│  · 按需音轨分离 │   显示点歌二维码       └────────┬─────────┘
│  · 后台管理    │                       │ 扫码 / 局域网
└──────────────┘                       ▼
                              ┌──────────────────┐
                              │  手机（多台同时）    │
                              │  H5 点歌台 /m/     │
                              │  搜歌·预览·收藏·切歌 │
                              └──────────────────┘
```

## 功能亮点

- **点歌台（投影仪，遥控器全键盘操作）**：三栏布局（歌曲列表 / 字母索引 / 二维码+快捷键），
  五个大类（歌名/歌星/排行/收藏/已点），歌曲行四态 UI（未选中/选中/已点/演唱中），
  已点歌曲后台自动预热，切歌零等待
- **遥控器键位**：OK=暂停；←/→ 双击=重唱/切歌、长按=×2 快退/快进；↑=切原唱伴唱；
  ↓=操作菜单；功能键=已点面板/切换大类；返回=点歌台⇄播放页（歌不停）
- **手机 H5**：扫码即用；拼音搜索（`zjl` 出周杰伦）、语种/类型筛选、置顶/打乱、收藏夹、
  **实时预览投影仪正在播的画面**（可全屏横屏）
- **NAS 后台**：批量勾选收藏/点歌/停用/移除、歌手管理（头像/地区/性别）、收藏夹页、
  批量导入（实时进度）、系统设置；免口令
- **播放兼容**：视频永远 `-c copy` 零转码；老 KTV 片源常见的 MP2 音轨在首次点唱时
  自动转 AAC + 换封装（mkv→fMP4 / mpg→MPEG-TS）并缓存；APK 直连原文件本地切音轨
- **健壮性**：网盘目录读取不全时自动保护曲库不误删；升级/重扫不丢点唱记录、收藏、音轨映射

## 快速开始

1. **NAS 装服务**：飞牛应用中心手动安装 fpk（构建方式见下，内置 Node22 + ffmpeg，开箱即用）
2. **投影仪装播放器**：安装 APK，填入 `http://NAS的IP:9188`（默认预填 `192.168.1.100`，可改）
3. **手机扫码点歌**：投影仪屏幕上的二维码，扫一扫即用

详细步骤、片源格式说明与故障排查见 **[docs/部署手册.md](docs/部署手册.md)**；
每个版本的改动见 **[docs/验收报告-v3.md](docs/验收报告-v3.md)**（含逐条功能验收记录）。

## 目录结构

```
home-ktv/
├── fpk/               ★ NAS 端 fpk 打包工程（manifest / cmd / config / wizard）
├── server/            ★ NAS 端服务源码（零第三方依赖，Node 22 内置 SQLite）
│   ├── server.js            入口（端口 9188）
│   ├── src/                 扫描 / 文件名解析 / 拼音 / 播放状态机 / remux
│   ├── public/              播放页 /play、点歌台 /m、后台 /admin
│   └── tools/               打包（build-fpk / fetch-runtime）与全套自动化验收脚本
├── android/           ★ 投影仪 APK 源码（Kotlin + Media3，本地瞬时切音轨）
├── docs/              部署手册 / 验收报告 / 需求确认书
└── .github/workflows/ push 自动编译 APK（GitHub Actions）
```

> 曲库视频请自备（命名如 `周杰伦-晴天-国语-流行.mkv`，解析规则见部署手册）；
> `server/config.example.json` 是配置模板，运行时会自动生成实际配置。

## 从源码构建

```bash
# 1. NAS 端 fpk（需要 Git Bash 的 tar/md5sum）
cd server
node tools/fetch-runtime.mjs     # 下载 Node22 + ffmpeg 静态运行时（国内镜像）
node tools/build-fpk.mjs         # 产出 ../fpk/ktv_<版本>_x86.fpk

# 2. 投影仪 APK（需要 JDK17 + Android SDK + Gradle 8.7；也可直接用 GitHub Actions 自动编译）
cd android
gradle assembleDebug             # 产出 app/build/outputs/apk/debug/

# 3. 本地测试（先放几个双音轨测试视频到 server/config.json 指向的目录）
cd server && node server.js
node tools/e2e-v2.mjs            # 31 项端到端验收
node tools/test-v3.mjs           # 22 项功能验收
node tools/check-ui-v120.mjs     # 手机端 UI 验收（需本机 Chrome）
```

## 硬件适配说明

- 针对 **J1900（无硬件编解码）** 设计：全链路只 remux 不转码，CPU 占用极低
- 片源在网盘（如 CloudDrive2 挂载）上时，首次全量扫描较慢（后台跑，不阻塞点歌）；
  支持多目录混用、本地优先，常唱的歌放本地盘可大幅提速
