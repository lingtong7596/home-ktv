# 投影仪端 APK（家庭 KTV Player）

Kotlin + Media3/ExoPlayer，直连 NAS 播放原始 KTV 视频（零转码），本地瞬时切原唱/伴唱音轨。

## 已编译产物

`../apk/HomeKTV-debug.apk` —— 直接拷到 U 盘装进投影仪即可，无需自己编译。

## 环境要求（自己重新编译时）

| 组件 | 版本 |
|---|---|
| JDK | 17 |
| Android SDK | Platform 34 + Build-Tools 34 |
| Gradle | 8.7（`gradle/wrapper/gradle-wrapper.properties` 已锁定） |
| AGP | 8.5.2 |

国内网络建议在 `gradle.properties` / `settings.gradle.kts` 里保留阿里云 Maven 镜像（本仓库已配好）。

## 编译

```bash
cd android
export JAVA_HOME=<jdk17 路径>
gradle assembleDebug --no-daemon
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 遥控器键位（v1.1.1）

播放页：

| 按键 | 短按 | 长按 |
|---|---|---|
| OK / 确认 | 暂停 / 继续（不弹系统控制层） | — |
| ← | 重唱 | ×2 速快退（松开即停） |
| → | 切歌 | ×2 速快进（松开即停） |
| ↑ | 切原唱 / 伴唱 | — |
| ↓ | 显示 / 隐藏操作菜单（唯一一组控制按钮） | — |
| MENU / 设置键 | 显示 / 隐藏已点面板 | — |
| 返回键 | 进点歌台（歌继续唱） | — |

点歌台内：

| 按键 | 作用 |
|---|---|
| MENU / 三道杠 | 依次切换大类：歌名 → 歌星 → 排行 → 收藏 → 已点 |
| 方向键 | 列表 / 字母索引间移动，OK 点歌 |
| 返回键 | 回播放页（歌不停）；歌手详情先退回列表 |

长按判定 420ms；快进/快退每 250ms 走 500ms（恰好 ×2 速）。
按钮焦点态 = 红底 + 白描边 + 放大；歌曲行四态：未选中深底 / 选中亮红底白描边 / 已点绿「✓ 已点」/ 演唱中金「● 演唱中」。

## 点歌台布局（v1.1.1，按手绘稿）

- 左栏：歌曲列表，序号红 / 歌名白 / 歌手青 / 类型蓝 / 语种粉
- 中栏：字母 + 数字索引大按钮（A-E F-J K-O P-T U-Y Z 0-9 全），打开时默认光标在 **M**
- 右栏：点歌二维码 + 快捷键说明
- 底部：大类栏（歌名/歌星/排行/收藏/已点）+ 语种/类型（或地区/性别）循环筛选 + 随机来一首
- 进点歌台时，播放页顶部的「正在播放」条与右上小二维码自动隐藏，避免重叠

## 功能一览

- 待机页：房间名、点歌二维码、IP 链接、点歌台/设置入口
- 播放：全屏、暂停/上下曲/重唱/切原唱伴唱/❤收藏/队列，本地瞬时切音轨零转码
- 已点面板：⬆置顶 / ✕删除 / 🔀打乱 / 清空，显示后台读音轨进度
- SSE 与服务端实时同步（点歌、切歌、收藏、预热进度、自动播放）
- 设置：服务器地址（默认 `http://192.168.1.100:9188`）、开机/空闲自动播放
