## 四、音轨自动识别 · 9/9 通过

| 场景 | 识别结果 | 依据 |
|---|---|---|
| 原唱在前 / 伴唱在前 | 均正确 | 音轨标题 |
| 英文标题（Original Vocal / Karaoke） | 正确 | 音轨标题 |
| 写成「伴奏」而非「伴唱」 | 正确 | 音轨标题 |
| 只标了其中一条 | 另一条自动推断 | 双音轨互补 |
| 三条音轨 | 取原唱/伴唱两条 | 音轨标题 |
| 标题缺失 | 交回全局默认 | — |
| 单音轨 / 无音轨 | 交回全局默认 | — |

**这里有一个必须如实说明的取舍**：识别依据是**音轨标题（title tag）**，不做逐首音频波形分析。

原因：J1900 上解码 5000 首音频做特征分析需要几十小时，收益远小于成本。而实际 KTV 片源里音轨标题几乎都写了「原唱/伴唱」，命中率很高。

兜底：识别不出来就用全局默认（0=原唱、1=伴唱），后台可对**单曲**一键对调，也可整体对调。
