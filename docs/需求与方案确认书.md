### J1900 带来的三条硬约束

1. **禁止转码。** 无可用硬件编解码，软编 1080p 单首可达十几分钟。全系统只允许 remux（`-c copy` 换容器）。
2. **首扫需要时间。** 5000+ 首逐文件 ffprobe，本地盘上约 25–45 分钟（后台执行、有进度条），之后增量扫描秒级完成。
3. **h265 在浏览器中大概率不可播。** 投影仪自带浏览器基本无 HEVC 硬解。因此**投影仪端以 APK 为主，H5 播放器降为兜底**。

## ⚠️ 二、关键风险：曲库挂在网盘上

你的路径 `/vol1/1000/ktv歌库（网盘挂载）` 指向的是 **CloudDrive2 挂载的 115 网盘**，不是 NAS 本地硬盘。这带来三个直接影响：

| 影响 | 说明 | 后果 |
|---|---|---|
| **扫描极慢** | ffprobe 每首要读文件头部，走 115 网盘单首可能 1–3 秒，5000 首 ≈ **1.5–4 小时** | 首次入库等待很久 |
| **播放易卡顿** | KTV 需要频繁拖动进度、切音轨，都触发随机读取；网盘延迟高、带宽受限 | 切歌缓冲、快进卡住 |
| **多端并发争带宽** | 投影仪拉 1080p 流的同时，手机端刷新封面/列表也走同一出口 | 多人使用时更明显 |

**我的应对设计（三选一，需要你定）**

- **方案 A：分层扫描（推荐）** —— 先只按文件名秒级入库（几分钟内全部可点可唱），音轨信息在**第一次被点唱时**才探测并缓存。好处：立刻能用、不阻塞；代价：某首歌第一次切原伴唱时多等 1–2 秒。
- **方案 B：全量预扫** —— 后台跑完 1.5–4 小时，期间可正常点唱已扫到的部分。好处：信息最全；代价：等待久，且每次新增歌曲都要再等。
- **方案 C：歌库迁到本地盘** —— 把 `ktv歌库` 复制到 NAS 本地存储（如 `/vol1/1000/KTV`）再扫描。**这是效果最好的方案**，扫描快、播放零延迟、切音轨瞬时。前提是你本地盘有足够空间。

> 无论选哪个，**我建议最终走向 C**。若空间不够，可只把「常唱的三五百首」放本地盘，其余留在网盘 —— 系统支持**多目录混合**（一个本地目录 + 一个网盘目录同时挂载），本地盘上的歌优先匹配。

## 三、曲库命名规范（已确认）

**规则**：`歌手文件夹 / 歌手-歌名-语种-类型.扩展名`

**解析示例（按你的真实样本）**

| 文件名 | 歌手 | 歌名 | 语种 | 类型 |
|---|---|---|---|---|
| `周杰伦-爱情悬崖-国语-流行.mkv` | 周杰伦 | 爱情悬崖 | 国语 | 流行 |
| `安七炫-面具-国语-流行.mkv` | 安七炫 | 面具 | 国语 | 流行 |
| `爱乐团-天涯-国语-流行.mkv` | 爱乐团 | 天涯 | 国语 | 流行 |
| `陈楚生-一个人的冬天-国语-流行.mkv` | 陈楚生 | 一个人的冬天 | 国语 | 流行 |
| `老狼&痛仰乐队-迪亚-国语-流行.mkv` | 老狼&痛仰乐队 | 迪亚 | 国语 | 流行 |
| `白冰 胡歌-美丽的神话-国语-合唱.mpg` | 白冰 胡歌 | 美丽的神话 | 国语 | 合唱 |
| `单依纯_VaVa毛衍七_吴宣仪_群星-VVS-国语-合唱.mkv` | 单依纯_VaVa毛衍七_吴宣仪_群星 | VVS | 国语 | 合唱 |

**边界处理**

- **歌名自带 `-`**：以「最后两段是否为合法语种/类型词」反向定位 —— 若倒数第二段在语种表内、最后一段在类型表内，则中间全部合并为歌名。例如 `陈奕迅-十年-粤语版-粤语-流行` → 歌名 `十年-粤语版`，不会误切。
- **段数不足**：`歌手-歌名` 视为无语种/类型；纯 `歌名` 则歌手回退取上级文件夹名。
- **歌手别名归一**：`老狼&痛仰乐队`、`白冰 胡歌`、`单依纯_VaVa毛衍七_...` 这类多歌手，同时拆出独立歌手名用于搜索，但展示保留全称。
- **类型字段的用处**：`合唱` 会打上「对唱」标签，手机端可一键筛出对唱曲目；`流行/摇滚/民谣/戏曲` 等作为分类筛选。
- **扩展名**：`.mkv` `.mp4` `.mpg` `.mpeg` `.ts` `.avi` 全部纳入扫描。

## 六、三端技术方案

### 6.1 NAS 端 · fpk 安装包

**包结构**（严格遵循飞牛规范，`.fpk` = 双层 tar.gz）

```
ktv-1.0.0.fpk
├── manifest              # appname/version/display_name/source=thirdparty/platform=x86
│                         # service_port=9188/checksum(app.tgz 的 md5)
├── app.tgz               # 应用本体
│   └── ktv/
│       ├── server/       # KTV 服务（Node，零第三方依赖）
│       ├── node/         # 内置 Node 20 运行时（linux-x64）
│       └── ffmpeg/       # 静态 ffmpeg + ffprobe（自带解码器）
├── cmd/
│   ├── main              # start / stop / status
│   ├── install_callback  # 建数据目录、初始化 SQLite、写默认配置
│   ├── upgrade_callback  # 升级保留曲库与配置
│   └── uninstall_callback# 停止进程、保留用户数据
├── config/
│   ├── privilege         # run-as: package（非 root）
│   └── resource          # 声明数据目录、端口
├── wizard/install        # 安装向导：填「曲库路径」
├── ui/config             # 桌面图标入口 → 管理后台
├── ICON.PNG / ICON_256.PNG
├── ktv.sc                # 防火墙放行 9188/tcp
└── health.json           # 健康检查 HTTP 200
```

**功能清单**

| 模块 | 说明 |
|---|---|
| 曲库扫描 | 按第三节规范解析；支持多目录（本地盘 + 网盘混合）；分层扫描（先文件名入库，音轨按需探测）；增量更新 |
| 拼音搜索 | 内置 2 万字离线拼音表，支持首字母 / 全拼 / 中文 / 歌手 / 混合，搜 `zjl` 出周杰伦 |
| 音轨识别 | 音轨标题 → 声道数 → 音频能量特征三级判定，结果按歌曲持久化，后台可对调 |
| 点歌队列 | 置顶、删除、切歌、多人并发、防重复提示 |
| 播放状态机 | 单一权威源，APK 与手机通过 SSE 实时同步，断线自动重连 |
| 视频推流 | HTTP Range 分段，支持任意位置拖动；对网盘文件做读取缓冲 |
| 二维码 | 服务端直出 PNG，地址变更自动同步 |
| 管理后台 | 曲库路径、扫描进度、音轨映射、缓存、密码保护 |
| 开机自启 | 由 fnOS 应用中心托管，NAS 重启自动拉起 |

**数据落盘**（卸载不删）

```
/vol1/@appdata/ktv/     ← SQLite 曲库、点歌记录、音轨探测缓存、配置
/vol1/@appconf/ktv/     ← 静态配置
```

### 6.2 投影仪端 · APK（大眼橙 X10 / Android 9）

**技术栈**：Kotlin + Media3 (ExoPlayer) + OkHttp，`minSdk 21`、`targetSdk 34`，release 签名。

| 功能 | 实现 |
|---|---|
| 全屏播放 | 沉浸式全屏、保持常亮、防休眠 |
| 音轨切换 | `TrackSelectionOverride` 运行时切换，**不重新加载、无卡顿** |
| 格式支持 | mkv/mp4/ts/**mpg(MPEG-PS)**；视频 h264/h265/mpeg2；音频 AAC/MP3/AC3/EAC3/FLAC/Opus |
| 自动连播 | 播完自动接下一首，提前预加载下一首 |
| 点歌二维码 | 展示 NAS 生成的 PNG，常驻屏幕角落；待机时放大居中 |
| 待机画面 | 大字二维码 + 点歌指引 + 已点数量 |
| 遥控器 | 方向键切歌/切原伴唱/呼队列，确认键暂停，返回键收起 UI |
| 异常兜底 | 音频编码不被支持时（如 DTS），自动回退到 NAS 的 remux 版本 |
| 网络 | 首次填 `192.168.1.100:9188`，之后永久记住；断网自动重连 |
| 启动自启 | 开机自动拉起并全屏（投影仪设置里授权） |

**编译方式**：本机装 JDK 17 + Android SDK 34 + Gradle 8.x（下载 2–3GB，约 10 分钟出包）。

## 八、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| **网盘挂载（CD2/115）** | 扫描慢、播放缓冲、并发争带宽 | 分层扫描 + 按需探测；建议迁本地盘或常唱曲目缓存本地（见第二节） |
| mpg（MPEG-PS）片源 | h265 之外的兼容性 | APK 用 PsExtractor 播放；视频为 mpeg2 时软解，1080p 可能掉帧 |
| 音轨自动识别误判 | 原伴唱颠倒 | 后台一键对调，支持单曲单独设置 |
| 部分片源单音轨 | 无法切原伴唱 | 标记「仅伴奏」，正常点唱 |
| 歌名含 `-` | 解析错位 | 反向定位语种/类型词表，中间合并为歌名 |
| h265 + 浏览器 | H5 兜底不可用 | 以 APK 为主路径 |
| 微信拦截 http | 手机打不开 | 内置复制链接兜底 |
| NAS IP 变动 | 二维码失效 | 路由器绑定静态 IP；APK 可重设 |
| fpk 安装被拒 | 装不上 | 严格按规范打包并回写 checksum，先「手动安装」验证 |
