## 三、本版顺带修复的隐患

1. **曲库误清空保护**：旧逻辑把「本次扫描没列出的文件」一律当已删除，115 网盘偶发列目录不全时会清空曲库。现改为：缺失数超过 `max(50, 50%)` 阈值时整轮跳过清理（日志 `[scan] ⚠️`），并对每个缺失文件做 `fs.existsSync` 二次确认。
2. **「从曲库移除」走黑名单**：删除只动索引，文件记入 `removed_files`，扫描跳过、可一键恢复（验收：移除后 404 → 恢复 → 重扫 6→7 首）。
3. **升级用户数据保护**：重扫/升级不覆盖 plays、last_played、added_at、orig_track、acc_track（e2e-v2 回归通过）。

## 四、遗留说明

- `.mpg` 片源在电脑浏览器上仍无法播放（浏览器不支持 MPEG-2 视频），页面会明确提示「去投影仪播放」——这是浏览器能力边界，非缺陷。
- 预热在网盘带宽极差时可关闭（后台设置开关），关闭后回到"首次点唱时处理"。
