手机浏览器只允许「受信任的 https 页面」使用麦克风。家里的 NAS 没有公网域名，所以要装一次这台 NAS 的根证书（10 年有效，只装一次）：

  1. 点这里下载 ktv-ca.crt（用手机浏览器打开本页再点）
  2. 打开手机 设置 → 安全（或 密码与安全）→ 加密与凭据 → 安装证书 → CA 证书
    选刚下载的 ktv-ca.crt，提示风险时选「仍然安装」
  3. 回到本页刷新（地址 https://…:9189/score/），这次不会再有红色警告，麦克风就能用了

iPhone：下载后用「设置 → 通用 → VPN与设备管理」安装描述文件，再到「通用 → 关于本机 → 证书信任设置」里把它打开。
